The issue is that many students who use such websites and programs like these don't leave feedback of any data for us to improve on. As a result, we aren't able to find out how many people succeeded or how many people found opportunities from this program.

As a result, we have our website, which is sort of an extension of the actual Coding in Color website with our gamified survey system.

the system works by monitoring how much work the students do and allowing them to answer surveys for tokens
<img width="1517" height="730" alt="image" src="https://github.com/user-attachments/assets/cc4ca203-277a-464c-bce5-1e5d47c7ef2f" />
Later, students can redeem online prizes based on monitoring if the student did the work or not. There are also options for feedback. Teachers can also view everything on the impact page. The rewards are supposed to motivate the students to do the work and give updates so we know how effective the program is.
<img width="1518" height="727" alt="image" src="https://github.com/user-attachments/assets/e32356ab-2c2b-4b04-aad8-a27cf6f70b51" />

tech stack

- **Frontend:** HTML, JavaScript (hosted on Cloudflare Pages)
- **Backend & Edge:** Cloudflare Workers, Node.js, Python
- **Database & Storage:** Cloudflare D1 (SQL)
- **AI & LLMs:** Claude (Anthropic), Gemini (Google), Cloudflare Workers AI

All of the main components of a website are mocked up, but the next steps are to connect everything and expand. There can also be leaderboards and more rewards with less age and learning limited feedback.
